SLIDER Api's =================

    Sliders are admin-managed. Each slider can target:
        - A set of specific PRODUCTS (type: "PRODUCT")
        - An entire CATEGORY (type: "CATEGORY")
        - An entire BRAND (type: "BRAND")
    Each slider also has an optional banner image.

    1. For ADMIN Only
        POST {{localURL}}/slider
            Authentication
            req.body[form-data]: {
                data: {
                    "title": "String",
                    "type": "PRODUCT" | "CATEGORY" | "BRAND",
                    "productIds": ["6a4d1d9fe46a05bfe8fdcc04"], // required if type=PRODUCT
                    "categoryId": "6a4a6a2bdfe6e7a891d1527c",  // required if type=CATEGORY
                    "brandId": "6a4d1b7de46a05bfe8fdcc01",     // required if type=BRAND
                    "active": true,                             // optional, default: true
                    "sortOrder": 0                              // optional, for ordering
                },
                image: File  // optional banner image
            }
            response: {
                "statusCode": 201,
                "status": true,
                "message": "Slider created successfully!",
